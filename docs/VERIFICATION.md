- [ ] King–Middleton 2次近似解との比較(`tests/test_king_middleton.py`、基準値は
  `tests/reference/king_middleton.csv`。AN-SOF の記事からの転記で、原典 King (1956) とは未照合)。
  分割数は「Δ/a ≥ 8 を満たす最大の奇数 N(上限 101)」で事前固定(Ω=12.5 → N=63、Ω=15, 20 → N=101)、
  許容誤差は R ±5 %、X ±5 Ω(事前固定、変更しない)。9 ケース中 8 ケースが許容内。
  外れたのは Ω=12.5, βh=1.6 のみ(X が +6.53 Ω。R は +4.77 % で許容内)で xfail(strict)。
  なお Δ/a ≥ 8 を守っても N を増やすと R・X は単調に増え続け(Ω=12.5, βh=1.6 で N=21→63:
  R 90.0→91.8、X 65.8→66.9 Ω)、N=81, 101(Δ/a 6.4, 5.1)ではさらに R 92.4、X 67.2 Ω に達する。
  Δ/a 違反だけではドリフトを説明できない。K-M 側の近似誤差・転記差・NEC2 側の影響は未切り分け
  Δ/a≥8 の範囲内でも N 増加で R・X が上昇する。NEC2 の電圧源は 1 セグメントに印加されるため、
  実効的な給電ギャップが N に依存することが原因との仮説(未検証)。太い導体ほど影響が大きい傾向と整合
