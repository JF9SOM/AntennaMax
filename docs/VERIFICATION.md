- [ ] QFH の NEC2 検証(事前固定の基準: 天頂の軸比 < 3 dB を 137.5 MHz と 435 MHz で、巻き方向を
  逆にすると天頂の支配的な円偏波の向きが逆になること)。経緯と結果:
  1. 初版(小ループを大ループと同じ極性で接続)は天頂の軸比が 7.62 dB(137.5 MHz)、12.49 dB
     (435 MHz)で基準を外れ、xfail(strict) にした。
  2. 診断: 現行形状で真下(θ=180°)の軸比は 0.90 dB / 0.39 dB、全利得のピークも θ=180°
     (3.70 / 3.90 dBi)で、ビームと良好な円偏波が真下に出ていた。仮説「小ループの給電極性が逆」を
     支持。
  3. 修正: 小ループの上部の接続端子を入れ替えた(給電極性の誤りの修正。基準・寸法は変更なし)。
     修正後、天頂の軸比は 1.37 dB(137.5 MHz)、0.72 dB(435 MHz)で基準を満たし、xfail を外した。
     真下の軸比は 4.87 dB / 10.20 dB に悪化、ピークは θ=0(3.50 / 3.69 dBi)。給電点
     29.9+4.7j Ω / SWR 1.70(137.5 MHz)、35.4+5.2j Ω / 1.44(435 MHz)。
  4. 巻き方向と偏波(給電点が上、天頂向き): 右巻 → LHCP、左巻 → RHCP(期待値は文献由来で、
     プログラムの出力から決めていない)。出典: AN-SOF
     https://antennasimulator.com/index.php/2022/11/22/qfh-antenna-for-noaa-satellite-reception/
     (左巻きヘリックスが RHCP、給電点が上のバックファイア構成を気象衛星用途として説明。
     巻き方向は偏波の向きと逆)、AMSAT-BB
     https://mailman.amsat.org/hyperkitty/list/amsat-bb@amsat.org/thread/LP3UGHL23MQEGJK57YOLFTRLC2BFH6RJ
     (指示により引用。Web 検索結果の抜粋で『RHCP は両ループ左巻き、LHCP は右巻き』の記述を確認。
     本文は HTTP 403 で未取得)。NEC2 の結果はこの期待値と
     一致する(左巻 → RHCP +3.47 dBic、LHCP −18.62 dBic @137.5 MHz)。
  独立エンジンや実測との照合、曲げ半径を形状に入れたときの変化は未確認
